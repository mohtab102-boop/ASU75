# كتاب ذكريات دفعة 75 طب عين شمس

موقع ثابت (HTML + CSS + JS) من غير أي سيرفر. الطالب يفتحه، يرفع صوره ويعدل النص، ويحفظ ملف مشروع.

## الرفع على GitHub Pages
1. اعمل Repository جديد وارفع الملفات: `index.html` و `style.css` و `app.js` (و `book-data.json` لما يبقى عندك).
2. من Settings ثم Pages اختار Branch: main و Folder: root ثم Save.
3. بعد دقيقة الموقع يشتغل على `https://USERNAME.github.io/REPO/`.

## طريقة العمل
- **الطالب:** يفتح الرابط، يضغط على أي إطار صورة لرفع صورة (بتتصغّر تلقائياً)، ويضغط على أي نص لتعديله. التعديلات بتتحفظ تلقائياً في متصفحه فقط. بعدين يضغط «حفظ ملف المشروع» ويبعت ملف `kitab-dofaa75.json`.
- **المنسق (إنت):** تفتح الملف اللي وصلك بزر «فتح ملف مشروع»، وتجمع المحتوى، وتحفظ النسخة النهائية. لو سمّيتها `book-data.json` وحطيتها جنب `index.html` في الـ repo، أي حد يفتح الموقع لأول مرة يشوف نسختك. زر «نسخة الدفعة الأصلية» يرجّع أي حد لها.
- **PDF:** زر «طباعة / PDF» ثم اختار Save as PDF، مقاس A4، والهوامش None، وفعّل Background graphics. أو ابعتلي ملف المشروع وأنا أطلعه PDF.

## ملاحظات
- كل ملف مشروع فيه نسخة كاملة من الكتاب بصوره، فلازم تدمج محتوى الطلاب يدوياً بنسخ الصفحات (نسخ / حذف / تحريك من أزرار فوق كل صفحة).
- لو عايز الطلاب يرفعوا صورهم على نفس الكتاب مباشرة من غير ما يبعتوا ملفات، محتاج قاعدة بيانات (Firebase أو Supabase)، لأن GitHub Pages ما بيحفظش بيانات.
- الخطوط من Google Fonts فمحتاج إنترنت.
